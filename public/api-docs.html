Backend Highlights

  • File-backed JSON storage for local/self-hosted persistence.
  • Anonymous session cookie for score submissions.
  • Rate limiting on public write and read-heavy API routes.
  • Protected admin routes using the x-admin-token header.
  • Authenticated Tamagotchi actions with server-owned stats, XP, coins, rewards, cooldowns, and idempotent request IDs.
  • BirdNET species catalogue, supplemented by Wikipedia/Wikidata domestic breeds.
  • Independent catalogue source caches with optional Airtable storage for drawings and scores.
  • Community pigeon drawings stored through the backend.
