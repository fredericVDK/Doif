# Pigeon Crumbs

A tiny static website: click anywhere on the screen to drop a breadcrumb, then one small pigeon arrives after one second to eat it.

Made with Codex.

## Deploy on Vercel

Import this folder as a Vercel project. The `api/index.js` function serves the site through Node.js, and `vercel.json` sends all routes to it.

## Run locally

```bash
npm start
```

Then open `http://localhost:3000`.
